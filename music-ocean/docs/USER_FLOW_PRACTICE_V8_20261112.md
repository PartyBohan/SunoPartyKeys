# V8 练习灯光与长音

基线 `abb5fe4`，2026-11-12。使用 Chrome 和隔离的 D 大调 MIDI 样本，按键事件与设备回报分开记录。

| 路径 | 结果 |
| --- | --- |
| 转调 | 样本包含 D 大调调号。练习页默认 C 调，C4/E4/G4 键位分别发出 D4/F♯4/A4；示范与伴奏沿用原始 MIDI 音高。浏览器检查键位与标识，测试校验数值。 |
| 充能 | 半速下，C4 需要 1 秒。Chrome 短按后仍等待 C4；按住超过 1 秒后推进到 E4。测试覆盖和弦各音独立计时，以及松开后重试。 |
| 接入 | macOS 识别 USB PartyKeys。Chrome 获得 SysEx 权限，匹配 MIDI 输入与输出，C4、E4 的提示发送无异常；暂停后灯光状态返回就绪。物理发光和实体键按压需用户确认。 |
| 页面 | 桌面和 667×375 横屏看到全宽预判区、薄边琴、目标音与跟弹按钮；375×667 检查竖屏重排。 |
| 安全回退 | 使用既有普通 MIDI 路径做输入；只向明确配对的 PartyKeys 总线发送 SysEx。释放已演奏音、关闭目标灯以及清理发现队列由生命周期管理。 |

本轮复用了 `fruit-webmidi-palette71-v1` 具名模式，适用于已识别的 PartyKeys/PartyStudio/SAM5704 配对。只在距击键线 0.45 秒内提示，并在相同窗口内接受按下；未按到线时等待。固定灯色和逐帧屏幕充能分开，避免每帧刷实体灯。USB 琴灯亮度、物理延迟和 BLE 路径尚需实物观察。无 MIDI 调号且不能可靠推断的曲谱会提示选择原曲调性。

界面参考 [Synthesia](https://synthesia.app/support/guide/firstSong) 的击键线和预判距离、[Midiano](https://midiano.com/) 的等待跟弹及音轨控件。
