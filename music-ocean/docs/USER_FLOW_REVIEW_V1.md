修复：手机标题不再把末字单独换行；人物图层高度与定位调整，避免人物被输入面板遮住；切语言清除旧语言提示；试听异步任务有版本号，停止后不会迟到开始播放；等待任务保留作品编号，避免重复提交扣额度；可停止本地等待而保留旋律。

代码检查：没有桌面 OAuth token 写入网页；API 密钥不进 localStorage；Suno 最大算力模式未启用；原歌曲音频与歌词未复制；Web MIDI 不请求 SysEx、不发送亮灯命令。产品保留四力度采样基线与合成回退。其他 API 是有明确契约的通用适配入口，需要对应服务兼容，不宣称支持所有 API。

待验收：等 Suno 返回同一个已提交任务并实际播放，连接真实 PartyKeys 验证按键和踏板。当前不能称为完整端到端验收通过。任务编号与服务状态已补入可展开的详情，手机端也保留查询入口。
