# V6 三步创作复测

基线：101a77b。2026-11-08，macOS Chrome。范围由用户本轮七项反馈确定；未修改琴键数量、MIDI 传输、音色、踏板或灯光协议。

## 用户可见的改动

1. 录旋律、选风格、作品三步始终出现在顶部。第三步需要真实保存的创作任务；等待与完成状态都在独立作品页。上方步骤可以返回已可进入的页面。
2. 第二页收为五张较小的官方风格卡，原句试听成为一行。上一步在左下，生成在右下，同属底部操作栏。改变为真实的三步状态，移除独立 showResult state，避免导航与结果面板状态分叉。
3. 作品页集中展示播放器、原句对比、返回版本、分享和下载。自动只读查询已有歌曲文件，优先使用站内 MP3，不创建新分享卡、不请求 Suno。不存在文件时才由用户点击准备，保留先报价再确认下载额度的流程。
4. 分享弹窗复用已准备好的音乐卡。处理快速打开弹窗时文件查询尚未返回的情况，异步准备状态到达后自动更新，避免误以为需要重新导出。
5. 背景增加冷暖色潮、较大的折射移动和色相变化，8秒连续循环；关闭动态或系统减少动态时静止。删除换光按钮。
6. 设置缩至桌面390像素、短横屏340像素宽，字号、间距、边框、遮罩均减轻；连接长说明折叠。
7. 页脚与设置均有更新记录入口，展示 V4–V6，双语内容描述用户能得到什么，不显示提交号、技术日志或虚构指标。

## 代码审核与限制

旧版使用两个状态决定同一页面，现由 step 统一。保存上次步骤时捕获挂载时的值，避免异步曲库返回前被初始首页状态覆盖。播放输入、弹窗互斥、隐藏页面停止录音、任务去重与恢复边界保留。

此轮为Chrome浏览器与尺寸模拟，未进行实体 USB/BLE、真机微信或iPad验证。自定义API下载依赖其音频端点允许浏览器读取；失败会引导到原服务下载。没有测试或宣称生成服务作曲质量提升。

后续观察点：用户是否能直接理解底部操作栏；作品未返回时是否知道可以离开后回来；用户会否使用提示词展开编辑。当前不添加新的引导弹层或追踪。
