# V9 USB 真机反馈修复

- 基线 `5d640ac`。用户报告 V8 直连 USB 琴灯未亮、按键时听见两声、跟弹未推进。旧页面最后收到 B3，同一时间谱面目标为 C4。
- 单台直连 PartyKeys 改用官方 USB RGB 模式 `0F 01` 与 CMD15。C4 使用物理索引 12；保留中转的 palette71 协议及设备配对检查。软件发送不代表物理 LED 已亮。
- 桌面自动请求 Web MIDI，授权后无需按连接按钮。优先使用唯一的 PartyKeys 输入，过滤同端口同键重复按下，后台标签不处理键盘输入。移动端用蓝牙提示，MIDI Browser 仍拥有配对流程。
- 已连接设备进入练习时预提示首组，正确实体键可开始跟弹。短音可轻按，长音保留充能。浏览器音频授权不会阻塞跟弹计时。错键显示实际音名，提前松开提示重新按住。
- Chrome 已用真实 USB PartyKeys 验证刷新后自动连接并送出提示。收到用户复测前，实体灯光、实体键推进与听感仍分别标记待确认。蓝牙提示可在响应式模拟检查，BLE 真机未验证。
