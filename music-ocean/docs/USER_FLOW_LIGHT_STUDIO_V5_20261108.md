## 修复与代码审核

移除主页人物图、背景视频元素及其已无读取方的 ready/ref/play 副作用，保留原资源用于历史作品和回滚。新增光组件使用矢量与 CSS，不加载新视频。减少动态与用户关闭动态均使光动画静止。没有添加逐帧 JavaScript。

把原来只编辑额外要求的框改为可编辑的完整说明；提示词、格式、语言均作为明确草稿维度，没有另藏“实际使用的增强版”。旧用户额外要求保留，迁移中文版时生成中文说明。改变风格、格式或文本会重置下一次新创作的请求标识，原任务恢复逻辑不变。

提示词大窗最初被全局 dialog margin reset 推到角落，已改为显式居中并在短屏复测。开发者工具缩放时 AX 坐标偶有偏移，改用截图中的实际控件位置完成输入验证，未据此修改产品布局。

## 后续建议与限制

- 用户若不熟悉编配术语，可先选卡直接生成；完整说明已填好，无需强迫逐项填写。下一轮可观察用户是否需要中文术语帮助，暂不增加首页解释负担。
- 未接实体 USB/BLE 琴，不宣称本轮进行了硬件验收；36键与已有 MIDI/audio 边界未改动。
- 本轮未新增付费生成或下载请求；生成服务返回的音乐质量仍由用户实际创作体验判断。
- 这是 Chrome 浏览器模拟，不是真机 iPad/iPhone 或微信验收。
