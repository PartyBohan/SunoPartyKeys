# V7 学弹这首歌

2026-11-09，基线 `42a8b5c`。复测在 Chrome 的隔离曲库进行。付费转谱使用模拟响应。

| 路径 | 操作与观察 | 结论 |
| --- | --- | --- |
| 第一次进入 | 从已完成作品的「下一步」进入第四步；选「成品转谱」时先显示套餐与积分确认 | 通过 |
| 导入与跟弹 | 导入有主音、和弦、鼓的样本；分别显示原轨和整理后的主旋律、和弦；C3、E3、G3 补齐后才完成；错音后可继续 | 通过 |
| 伴奏与回访 | 单独切换鼓轨静音；刷新后返回第四步，导入谱仍可使用 | 通过 |
| 界面与设备 | 桌面和 iPad Mini 模拟视口检查工作台。375×667 竖屏检查标题和按钮顺序；667×375 横屏一屏显示完整琴键、跟弹和返回按钮 | 通过，Chrome 视口模拟 |
| 服务与隐私 | Suno 同一成品开始、等待、重复点击和缓存复用；跨账号无法读取、转谱或导入 | 通过，自动化 |
| 键位与主题 | 第一、四步共用键盘组件。21 个白键、15 个黑键及 36 键布局由同一映射生成。两页共用显示屏底色、网格及音符色 | 通过，代码和浏览器 |

校验包括 TypeScript、前后端生产构建及 52 个回归测试。试听和练习播放使用同一钢琴音频库，退出练习、弹出设置或失焦会停止练习时钟。转谱结果、用户导入和原始录音按来源区分。主旋律和和弦是自动整理的练习参考。

后续验证点是使用已启用 Suno Studio 的账号转一首真实完整作品，再对照源曲抽查音轨和和弦，以及用实体 PartyKeys 检查 MIDI 输入。当前测试未扣 Suno 积分。
