# 国内音乐卡迭代验收 · 2026-11-08

范围：将国内站的 Suno 外链分享改为可播放的手机音乐卡。基线为 11184b8，运行代码 964e255。保留已有 MIDI、钢琴、任务状态机、原始旋律和其他 API。用户确认暂不接入认证微信应用，先完成微信内的 H5 音乐卡页面；不宣称原生微信音乐气泡。

## 核心行为

- 国内站的分享面板只为完成的 Suno 作品准备卡片；先确认所有权，再导出当前选择的一个版本。
- 新增 download 授权单独发起。普通连接仍只请求原来的五项 scope。Suno 要求下载额度时，先展示明确报价，再由创作者点击确认，不自动扣费。
- 成品 MP3 与 PNG 封面保存在阿里云持久卷；分享链接为国内 `/s/<192-bit token>`。朋友无需登录，播放与拖动只读取国内文件，不发起 Suno 请求。
- 原始任务、账户凭据、临时导出 URL 和剩余下载额度不会出现在公开卡片数据中。
- 分享页有封面、歌名、播放进度、原始音符图、分享按钮及创作入口；动态唱片尊重减少动态设置。
- 图片卡的二维码改指向国内音乐卡。创作者可以停止分享，旧链接随即返回 404，原歌曲和任务保留。

本地夹具不包含真实 Suno 成品，没有进入生产包或生产数据库。正式收听复测已完成：

- 获用户允许后，仅为所选现有歌曲点击一次“使用 1 个下载额度”。官方 MP3 成功返回并写入阿里云；没有生成新歌曲。
- MP3 共 2,006,411 字节，实际媒体时长 90.48 秒，双声道、48 kHz。原 provider 元数据为 90.44 秒，编码封装时长略有不同。
- Chrome 无痕窗口直接打开正式分享卡，不登录也能播放；观察到进度 32 秒，点击进度条跳到约 71.4 秒后继续播放，最后在约 78.8 秒暂停。
- 无 Cookie 请求卡片 JSON、HTML、PNG 封面与完整 MP3 均成功；Range 206 的第 1000–1999 字节与完整 MP3 对应片段一致。公开 HTML/JSON 未包含 Suno 原站 URL、账户额度或临时下载地址。
- 正式手机页面在 iPhone 16 的 393×852 Chrome 模拟视口截图，完整封面、播放与分享区域可见。
- 创作者面板复制显示“已复制”，并成功下载新的二维码图片卡；macOS Vision 实际识别二维码，确认目标为国内音乐卡。具体分享 token 与完整校验摘要只保留在本地交接文件，不写入公共仓库。

## 自动化与代码审核

33 项测试通过；TypeScript、Web 与 Node 生产构建通过。新增测试使用真实本地 HTTP、SQLite 与临时目录，mock Suno，不消耗额度。覆盖：仅所有者发布、未知卡 404、未完成卡不公开、下载 scope 单独申请、先报价后确认、并发点击只确认一次、旧授权标签不覆盖正在导出的卡、匿名 MP3 Range / HEAD、公开数据不泄露凭据、HTML/JSON 转义、单一预览描述、停止分享、无效导入与重复创建合并。

有意保留 native audio 和已有任务保存逻辑。只增加独立分享数据，不用公开歌曲 ID 代替私有作品身份。播放器卸载暂停，复制提示计时器与海报 object URL 在清理时释放。没有加入分析追踪、虚构播放数、评论、点赞或自动循环下载。

## 限制与建议

1. 用户第一次分享需要新增下载授权与额度确认；OAuth 回调已恢复到原作品面板。后续用实际新用户观察核验是否仍会迷路，不把单次开发验收描述成访谈。
2. 没有认证微信账号时，微信聊天中显示何种链接预览由微信决定；已提供服务端标题、描述、PNG 封面及音频元数据，但没有宣称原生音乐卡接口已接入。
3. 当前导出上限为 4.2 MB，适用于本产品约 90 秒的歌曲。超限与导出拒绝必须显示真实失败，不能用原始旋律代替成品。
4. 尚未进行真实微信手机、实体 iPad、USB/BLE MIDI 验收。本轮不改变硬件行为，也不增加硬件验收声明。
